<objective>
Add `--dry-run` (D-09) to the swap tool and prove the property the whole design
exists for: running the same script a second time with the two tree roles
reversed restores the original layout exactly (D-08).

Purpose: D-09 gives the developer a preview before a tool that physically moves
real files touches anything. D-08 is the phase's headline claim — a true round
trip achieved with zero stored location metadata — and it is only a claim until
an assertion compares both trees before and after a there-and-back run.

Output: a complete, previewable, round-trip-verified `retain-dir-struct-4-revert.zsh`.

This plan is expected to require little new production code beyond the flag. If
the round trip does not close, the asymmetry is a real defect in Task 1's path
derivation and is fixed here, not worked around in the test.
</objective>
