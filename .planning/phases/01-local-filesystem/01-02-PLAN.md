**Read this before starting — same misdiagnosis as plan 01-01.**

`LOCALFS-02`, `CONCERNS.md`, and `CONTEXT.md` D-02 state that `file_map` lookups "silently return empty" because the `find | while` loop runs in a subshell. **That is false for zsh**, which runs the last element of a pipeline in the current shell. Verified on zsh 5.9 against the real script: the lookup already resolves correctly and prints real absolute paths today. Treat this as hardening — it removes the file's hidden dependency on a non-obvious zsh guarantee that breaks silently if another pipeline stage is ever appended — not as a bug fix, and do not describe it as one in the commit message or summary.
