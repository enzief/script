Every privileged live command in this plan is text handed to the human, never something an agent runs. Do not plan around, retry into, or "just try" a sudo call.

**This is bash, not zsh.** The `print -r --` convention from the local-filesys and manga work is zsh-only and does not apply here (established as D-01 of the prior plan). Use plain `echo`, with `>&2` on anything that is a warning.
